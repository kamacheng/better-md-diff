# 0.4.1 — Fix paragraph alignment around repeated blank lines

## Fixed

- Multiple small paragraph edits mixed with changes to blank lines could align unrelated old/new paragraphs, show a misleading separate deletion range, and give individual restoration actions an unexpected scope.
- Ambiguous blank-line anchors are now refined using jsdiff's character comparison, while unchanged nonblank context stays fixed. The reproduced `~3`, `~5`, `−6` case now has two correctly paired modifications: 3 old/current lines and 5 old/current lines, with no spurious six-line deletion.
- Regression coverage verifies that restoring either group leaves the other edits intact, and native undo restores the exact pre-restoration text in Source mode and Live Preview.

## Compatibility and limits

- No dependency or minimum-host-version changes: desktop Obsidian **1.8.0+** and local Git are still required.
- Spaces, tabs, final-newline differences and genuine deletions remain visible. No automatic folding or content filtering is introduced.
- Refinement is bounded to 20,000 characters of component text and the remaining 200ms diff budget; oversized, timed-out or weaker alignments retain the ordinary line comparison. This is not semantic or moved-paragraph detection. Always review the restoration preview before confirming.
- Git stays read-only. Restoration retains confirmation, cancellation, fresh HEAD/buffer checks and one undoable editor edit.
- Accepted-baseline review and GitLab integration remain unavailable.

## Validation

- **239 automated tests**, lint, strict type checking, build and release consistency checks.
- **43 isolated Obsidian checks per language**, English and Chinese, including the affected pairing/flags/restoration/undo scenario in Source mode and Live Preview.
- 192 blank-edit/direction combinations and 200 repeated-content round-trip fixtures; real insertions/deletions, Unicode, whitespace and LF/CRLF coverage.
- Long-document and 1,000-line-deletion stability checks, plus 36 whitespace-layout cases.
- Production dependency audit reports no known vulnerabilities. The three previously disclosed moderate development-chain findings around the SDK's Moment dependency remain; those npm packages are not bundled into the plugin. Provenance verification is not a security audit.

## 中文更新说明

**修复重复空行造成的段落错配及逐项还原范围问题。** 多段文字同时小幅修改、部分空行变成正文时，旧版可能把不同段落配到同一项，并额外显示整块删除。复现中的 `~3`、`~5`、`−6` 现在正确对应两项修改（旧/新各 3 行、各 5 行），不再出现那项错配的六行删除。

源码模式和实时预览均验证了旧新段落对应、旗标、独立还原及原生撤销；还原一项不会影响另一项。保留所有空白及真实删除差异，不靠隐藏内容、自动折叠或扩大还原范围解决问题。

仍使用 jsdiff，而非重写核心算法。局部细化有 20,000 字符和剩余 200ms 预算限制，超限或未获得足够完整行对应时保留普通行级比较；并非通用语义/段落移动识别。**还原前仍应核对预览。**

最低宿主版本、依赖、只读 Git 和还原安全校验均不变。239 项自动测试、中英文各 43 项隔离宿主检查，以及稳定性、空白布局回归通过。生产依赖审计无已知漏洞；已有 3 项仅开发链中等风险提示仍保留披露。完整认可审阅与 GitLab 对比尚未开放。
